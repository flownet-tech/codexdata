ModelDex

An open model catalog served as static JSON from Cloudflare Workers: a mirror of the official OpenAI Codex model catalog (what the Codex client itself fetches from chatgpt.com/backend-api/codex/models), plus a cross-provider model registry.

Endpoints (v1)

Path What
/v1/index.json Discovery: endpoints, last sync summary, licenses.
/v1/codex/models.json Latest official Codex catalog envelope {"models":[…]}, unmodified. ETag + If-None-Match supported.
/v1/codex/meta.json When it was fetched/checked, client version used, content hash, source plan label.
/v1/codex/snapshots/index.json Recent immutable snapshots; each at /v1/codex/snapshots/<sha256>.json.
/v1/codex/changes.json Models added / removed / changed, newest first.
/healthz 200 when the mirror has a catalog fetched within 24h; 503 otherwise.

Caveats

  • The Codex catalog reflects one dedicated ChatGPT account's view (plan label in meta.json); other plans may see a different list.
  • It is fetched with the latest published @openai/codex client version. Older clients ignore unknown fields.
  • If the upstream is unreachable, the last successfully fetched catalog keeps being served.
